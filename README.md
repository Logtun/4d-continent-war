# 4D Continent War

Live six-continent check-in standings for the 4D Labs Season 1 campaign, plus shareable "I checked in for <continent>" cards.

Live: https://4d-continent-war.sites.tab.bot

- Season board: 4D Labs' public dApp stats (Snaps per landmark), refreshed every minute
- Today's battle: check-ins sent to the 4D Labs check-in contract on BNB Chain since 00:00 UTC
- Rally section: how to check in at each continent's landmark
- Share cards: 1200x675 PNG per continent with live rank, share on X

Runs as a single Worker (`_worker.js`) with static assets and one R2 bucket binding (`FILES`) for saved cards.

Community-built by [@iamlogtun](https://x.com/iamlogtun). Not affiliated with 4D Labs.
